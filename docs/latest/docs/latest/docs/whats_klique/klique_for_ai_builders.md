# Klique for AI Builders

> Klique overview for AI Builders, covering model development, remote development environments, and application publishing.

AI Builders train, test, and deploy AI models, and leverage AI to build organizational applications. 
AI Builders get self-serve access to governed, managed compute and a path from development to
production, without provisioning infrastructure or operating Kubernetes. What they build can then be shared with the
rest of the organization through Klique.

![AI Dev center](../img/gif/ai_builder.gif#light-mode-only)
![AI Dev center](../img/gif/ai_builder_dark.gif#dark-mode-only)

## Build and deploy models

AI Builders build custom AI models and deploy them as endpoints that can be used throughout the organization.
Training and deployment run on managed compute, so a model goes from development to a live, governed endpoint without setting up serving infrastructure. See the
[AI MLOps Workbench](../ai_engine/klique_ai_workbench.md) and
[One-click Inference Service](../deploying_models.md).

## Full-featured AI Workbench

AI Builders run the workflows that support model development end to end, including experiment tracking, model and data
management, and pipeline orchestration. See the [AI Workbench](../ai_engine/klique_ai_workbench.md) and
[data management](../hyper_datasets.md).

## Develop on remote environments

AI Builders work on Klique-managed shared compute clusters or GPU-backed cloud instances through Klique's remote
development environments, getting the power of a remote GPU machine with the responsiveness of local development, and
with no infrastructure to provision. See
[remote development environments](../orchestration_engine/gpuaas_remote_ides.md).

![VS code app](../img/apps_vs_code.png#light-mode-only)

## Author and publish applications

AI Builders author custom organizational applications and publish them for others to use. Klique gives them the
orchestration capabilities to host and deploy applications without handling the underlying infrastructure.
Users can then launch applications on the compute the organization makes available.
