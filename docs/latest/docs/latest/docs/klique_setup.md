# Klique Setup

> Klique Setup: the one-time tasks for choosing a deployment target and bringing a Klique deployment online.

Klique Setup covers what you do once to bring a deployment online: choosing where Klique runs, installing the control
and workload planes, and completing the first-run decisions a deployment needs before real users onboard.

Once the deployment is running, you can make adjustments that you can find in [Klique Configuration](klique_configuration.md),
and ongoing operational tasks are covered in [Platform Administration](klique_maintenance.md).
