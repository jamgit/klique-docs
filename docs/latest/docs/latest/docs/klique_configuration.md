# Klique Configuration

> Klique Configuration: the settings you adjust after deployment to change platform behavior.

Klique Configuration covers the settings you adjust after a deployment is running, for the different scenarios where
you need to change how the platform behaves. Unlike the one-time decisions in [Klique Setup](klique_setup.md), these
settings are meant to be revisited, without reinstalling anything.

Operational tasks, rather than behavior changes, are covered in [Platform Administration](klique_maintenance.md)
instead.
