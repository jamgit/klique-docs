returned schema represents the various fields that can be used to query these
versions in a Lucene query. In case of conflicting schema types between
versions, conflicting items will not be returned.

Parameters​

TypeNameDescriptionSchema
Bodyrequest
required		request bodyrequest

request

NameDescriptionSchema

optional		The ID of the dataset. Either dataset or versions should be specifiedstring

optional		Type of the schema to return (defaults to frame).
- "frame" - all the fields for query at frame level will be returned
- "roi" - all the fields for query at frame.rois level will be returned
- "sources" - all the fields for query at frame.sources level will be returned		datasets.schema_type_enum
versions
required		Dataset version ids. The resulting schema is a merge of the common fields from
all the specified versions.		< string > array

Responses​

Response 200
