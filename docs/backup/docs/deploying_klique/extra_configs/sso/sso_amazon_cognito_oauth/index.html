Amazon Cognito OAuth

This guide explains how to configure Amazon Cognito as an OAuth provider for Klique Single Sign-On (SSO).

Configuration requires two steps:

  1. Register and Configure the Klique application in Amazon Cognito
  2. Identity service configuration in the Klique Server

Configure Amazon Cognito​

  1. Select a user pool in Amazon Cognito. Make sure the pool includes the required user attributes "email" and "preferred_username"
  2. In the user pool App Integration section, create an app client for Klique with the following properties:
    • App type - Confidential client
    • Client secret - Generate a client secret
    • Hosted UI Settings > Allowed callback URLs > add the URL <klique_webapp_address>/callback_cognito
    • OAuth 2.0 grant types - Authorization code grant
    • OpenID Connect scopes - OpenID, Profile, Email

Configure Klique Server​

  1. Define the following environment variables in your secret manager or runtime environment:
    • COGNITO_AUTH_CLIENT_ID
    • COGNITO_AUTH_CLIENT_SECRET
  2. Set the following environment variables for the apiserver:
    • KLIQUE__services__login__sso__oauth_client__cognito__authorize_url=<authorization endpoint> (Authorization endpoint format should be <cognito_domain_of_the_pool>/oauth2/authorize)
    • KLIQUE__services__login__sso__oauth_client__cognito__access_token_url=<token endpoint> (Token endpoint format should be <cognito_domain_of_the_pool>/oauth2/token)
    • KLIQUE__secure__login__sso__oauth_client__cognito__client_id="${COGNITO_AUTH_CLIENT_ID}"
    • KLIQUE__secure__login__sso__oauth_client__cognito__client_secret="${COGNITO_AUTH_CLIENT_SECRET}"

External Identity Provider​

If the user pool relies on an external identity provider, add the following environment variable:

KLIQUE__services__login__sso__oauth_client__cognito__identity_provider=<external_idp_name_as_defined_in_the_user_pool>

Default Company Assignment​

To allow the identity provider to automatically create new users in Klique without requiring them to be whitelisted in advance, set the following environment variable:

KLIQUE__secure__login__sso__oauth_client__cognito__default_company="<company_id>"

Custom Display Name​

To customize the provider’s login option appears in the Klique login screen:

KLIQUE__services__login__sso__oauth_client__cognito__display_name="New display name"
