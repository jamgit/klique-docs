# Use Cases

> Workflow guides for experiments, model endpoints, remote IDEs, interactive demos, custom apps, task scheduling, token quotas, and agentic sessions.

This section walks through complete Klique workflows end to end: what to do, in what order, and which reference
pages to consult along the way. 

* [Managing Experiments](experiment_management.md) - Instrument training code with the ClearML SDK,
  then track, compare, reproduce, and organize runs in Klique.
* [Deploying Model Endpoints](deploying_model_endpoints.md) - Turn a trained model into a live,
  secure inference endpoint using Klique's deployment solutions.
* [Launching a Remote IDE](launching_remote_ide.md) - Launch an SSH session, JupyterLab, VS Code, or virtual
  machine remote desktop on remote, managed compute.
* [Building Interactive Model Demos](building_interactive_demos.md) - Spin up a Gradio or Streamlit interface to
  demo a model interactively.
* [Building Custom Applications](../deploying_klique/app_custom.md) - Package your own Python code as a
  Klique application with a configured launch form and dashboard.
* [Scheduling and Triggering Task Execution](task_trigger_schedule.md) - Run tasks on a schedule or
  automatically in response to platform events.
* [Token Limit and Quota Control](token_quota_control.md) - Layer gateway-wide, model, user, and
  group-level token quotas and rate limits through the LLM Gateway.
* [Launching an Agentic Coding Session](launching_agentic_session.md) - Choose among Claude Code, Codex, and
  OpenCode, launch a session on managed compute, and return to a stopped one.
