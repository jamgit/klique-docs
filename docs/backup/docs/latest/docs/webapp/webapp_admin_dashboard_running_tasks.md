# Running Tasks

> The Admin Dashboard Running Tasks tab, which lists running tasks and app instances across the tenant, including those of other users.

The **Running Tasks** tab of the Admin Dashboard lists the running tasks and app instances across the tenant,
including those belonging to other users.

Clicking an app instance opens its page in the [AI Builder view](role_based_ui.md#ai-builder)
in a new tab, since inspecting an instance uses the Builder functionality.
