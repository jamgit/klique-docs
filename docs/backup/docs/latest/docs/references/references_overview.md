# References

> Klique reference pages for the ClearML SDK, Legacy SDK (allegroai), client configuration, the Orchestrator, MCP server modules, and the Server API.

Reference pages document individual components in isolation. Unlike [Use Cases](../getting_started/use_cases.md), which walk through complete workflows, these pages are organized
by component, for looking up a specific class, setting, or endpoint.

* [ClearML SDK](../clearml_sdk.md) - Core ClearML SDK concepts Klique uses, including projects, tasks,
  hyperparameters, artifacts, models, pipelines, and datasets.
* [Legacy SDK (allegroai)](hyperdataset/hyperdataset.md) - The legacy allegroai SDK's Hyper-Dataset classes
  (HyperDataset, HyperDatasetVersion, SingleFrame, FrameGroup, Annotation, DataView), maintained for critical bug
  fixes only.
* [Client Configuration](../configs/client_configuration.md) - Configuration precedence (CLI arguments, environment
  variables, configuration vault, `clearml.conf`) shared by the ClearML SDK and Agent.
* [Orchestrator](../orchestrator.md) - The Orchestrator and Executor roles, how they map onto each fabric, and the
  capabilities of the ClearML Agent Klique employs for both.
* [MCP Server](mcp_server/overview.md) - Klique MCP server modules (apps, events, models, projects, queues, tasks,
  users, workers) and hosted skills, as tools, resources, and prompts.
* [Server API](api/index.md) - The Klique REST API reference.
