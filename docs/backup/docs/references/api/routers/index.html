POST /routers.publish_route_app​

Description​

Internal. Publish a route as a url-app tile in apps.get_apps, with the admin-
chosen presentation metadata. A route may be published as several tiles, each
identified by its (category, name): publishing the same pair again edits that
tile, a new pair adds another. Returns the tile's app_id. To remove tiles use
delete_published_route_apps. Sets only presentation/RBAC fields on the route
(not routing), so it does not require the route to be disabled. Tenant-admin
only (allow_roles + read_write on the route). The tile's URL is derived at read
