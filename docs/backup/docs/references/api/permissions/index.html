POST /permissions.add_or_update_access_rule​

Description​

Edit existing entity access rule or add a new one

Parameters​

TypeNameDescriptionSchema
Bodyrequest
required		request bodyrequest

request

NameDescriptionSchema
access_permission
required		The access permission that this rule grantspermissions.access_permission_enum
description
required		The description of the rulestring
entity_id
optional		ID of the entity that this access rule gives access to. Shape depends on
entity_type: - project/task/model/dataview/dataset/dataset_version/queue/route:
the entity's Mongo doc id, or "" for all entities of that type. For project
rules, null can also be passed for the top level entities access. - app
(DAG-19215): the Application.app_id string declared in the app's HOCON
template (NOT the Mongo doc _id) — e.g. "vscode", "hpo-app". "" grants all
apps. - app_category (DAG-19215): the category string itself — e.g. "AI dev",
"deploy". The string is compared byte-for-byte against
Application.info.category at runtime; mismatched strings produce inert rules.
"*" grants all categories. For app and app_category, the entity_id is NOT
enriched server-side on read (entity_name / entity_display_name come back
null); render the raw entity_id in the FE.		string
entity_type
required		The type of the entity that this access rule gives access topermissions.entity_type_enum
groups
required		The list of the rule user groups< string > array
id
optional		Rule id. If specified and the rule with the id is found then it is updated.
Otherwise the new rule with this id is created		string
name
required		The name of the rulestring
users
required		The list of the rule users< string > array

Responses​

HTTP CodeSchema
200Response 200

Response 200

NameDescriptionSchema
id
optional		The id of the created or edited access rulestring
name
optional		The name of the rulestring
